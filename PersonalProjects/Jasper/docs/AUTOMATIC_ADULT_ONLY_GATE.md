# Automatic adult-only gate

This is a private Jasper-only project.

- Jasper is permanently configured as an adult reader born in 1999.
- Jasper is not asked for an age, participant roster, 18+ checklist, or repeated confirmation.
- `explicit_detailed` is the fixed generation mode.
- Romantic/sexual characters are automatically constrained to adult versions.
- If a canon character is younger in the default era, generation uses an adult/post-canon/adult-era version.
- If a prompt explicitly states an under-18 participant, adult generation is blocked.
- The no-minors rule is enforced by project configuration and generation prompts, not by user-entered status fields.
