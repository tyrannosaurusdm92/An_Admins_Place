# Package manifest

- Root entry point: `index.html`
- Styles: `css/book.css`
- JavaScript: `js/app.js`, `js/cyoa-story-engine.js`, `js/fanfic-data.js`
- Bundled data: five routes under `json/`, each with `series.json` and `01.json` through `40.json`
- Assets: `assets/book-cover.png`, `assets/paper.jpg`, `assets/page-flip.wav`
- Documentation: `docs/README.md`, `LICENSE.txt`, `MANIFEST.md`, `CONTENT_AUDIT.json`, `STORY_BIBLE.md`, `RESEARCH_AUDIT.md`, `VALIDATION.md`, `CHANGELOG.md`

There is one entry point, no nested ZIP, and no imported poetry, original-story
library, or reference-book JavaScript. The cover image belongs to this Jasper
package; the separate reference book supplied the interaction pattern only.
