How to use it

Drag modules into the canvas, select them, then use the inspector. Text is directly editable in the module. Code imports attach HTML/CSS/JS/JSON to whichever module is selected.

Shortcuts

  • Delete removes the selected module.
  • Ctrl/Cmd + S saves locally.
  • Drag the pill at the top of a module to move it.
  • Drag the bottom-right corner to resize it.

GitHub + Apps Script

The editor cannot publish directly without your GitHub/Google login, but it exports a folder ready to upload. For backends, copy backend/Code.gs into Google Apps Script and deploy as a Web App.
